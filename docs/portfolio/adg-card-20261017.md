- 1440 / 1024 / 768 / 375px：分别为 3 / 3 / 2 / 1 列，无横向溢出；实际图片加载，标题和用途完整换行。
- 验证首屏作品锚点、默认动画计时实际推进、结果与未读提示出现、第 0 秒复位、hover 图层对齐、键盘焦点、Enter 打开 ADG、离屏暂停、减少动效降级、中英文内容与关于页入口。
