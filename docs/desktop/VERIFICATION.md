## 证据范围

本轮主要验证集成影响的路径。窗口动画实现沿用已验收的独立桌面版本，重新执行了行为回归；本轮没有重新录制全部动画，也没有进行真实 Safari／实体 iPhone 测试。

Python 静态预览不会应用 Cloudflare `_headers`。集成测试在浏览器网络响应中重现 `SAMEORIGIN`，验证站内嵌入；生产响应头仍须随正式发布后复核。本记录对应部署前的本地验收，不能单凭本记录认定公网已经更新。

原 Blog 第三方视频／统计脚本已有控制台警告或加载延迟，不能据此声称全站控制台零警告。已有文章 `2026-05-22-AI-应用的真正分水岭-不是提示词` 引用的 `../input/image.png` 在原项目中缺失，记录于 `static-report.json`，本轮没有虚构或替换该图片。
