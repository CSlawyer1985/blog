Skill 选品学：为什么“律师助手”这类大包不值得装

本文目录 名字和里子，是两回事 四条选品原则 反着用：Skill 是免费的学习资料 星标高不代表适合你 最后：别看名片，看交接清单

打开任何一个智能体的技能市场，法律区永远是那几副面孔：“精英律师”“律师助手”“全能法律顾问”。名字一个比一个响，图标一个比一个亮。

我但凡看到这类大包，就不想装。

名字和里子，是两回事

一个 Skill 的表现好不好，跟它的名字没有任何关系。你千万不要看到一个“精英律师”，就觉得它审出来的一定是精英律师的水平。反过来也完全可能：一个叫“草根律师”的，里面的规则写得非常棒，那它才是好的那个。

里子在哪？在 Skill 的文件夹里。入口文件怎么写的、有没有分支规则、有没有能力边界、有没有一份“什么情况不要这样做”的反模式清单——这些东西决定了它的表现，而不是图标和简介。

四条选品原则

第一，高频且窄。这是我个人最硬的一条标准。窄到只覆盖一个具体场景，比如“建工合同价款结算条款审查”；高频到你每周真的会用。一个号称什么法律问题都能答的 Skill，你想想就知道：要支撑这个承诺，它里面的规则得写成什么样？大概率是每类都只有泛泛的几条。

第二，装上之前，打开看里子。多数平台现在都能直接看 Skill 的内容，不用装到本地。看三个检查点：有没有写清能力边界（能做什么、不能做什么）；有没有反模式清单（作者知不知道这件事容易在哪里翻车）；有没有分支规则文档（还是只有一个入口文件撑门面）。三条都有的，作者大概率是真干过这件事的人。

第三，破除平台幻觉。不要默认“平台上的 Skill 就是质量高的”。平台的运营者是技术人员，他们筛不了跨专业的内容质量。这不是批评平台，是提醒你：筛选的责任在你。

第四，少装。装一百个 Skill，启动时它们的名字和描述都会被读一遍。质量参差的描述多了，该调起来的调不起来，不该调的乱调。囤货不如精挑。

反着用：Skill 是免费的学习资料

就算你一个不装，Skill 市场也值得逛。

我的一个习惯：遇到没干过的活，先去找这个方向星标高的 Skill，把它的包文件读一遍——它怎么拆步骤、每一步的标准是什么、哪些地方设了防错。这等于把别人做这件事的方法论拆开给你看。

然后你会发现一个妙用：哪怕最后不用 AI，这些拆解也能指导你自己人肉干这件事。看别人的 Skill，本质上是读别人的操作手册。

星标高不代表适合你

星标高只代表受欢迎，不代表适合你的业务。装上之后先用三个你熟悉的场景实测，对它容易翻车的点心里有数，再放进日常流程。

最后：别看名片，看交接清单

选 Skill 和请助理是一个道理。

名片上印着“精英律师”的，不见得能干好活；简历朴实但交接清单写得清清楚楚的，才值得托付。
