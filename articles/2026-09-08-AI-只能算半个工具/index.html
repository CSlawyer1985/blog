AI 只能算半个工具

本文目录 工具的顶点，和 agent 的起点 认知是乘数 培养与管理 有人说，这不就是“人不行怪人”吗 半年的窗口

前阵子有位律所同行问我：他们所半年前统一采购了 AI 工具，为什么到现在，有人用出了质变，有人连登录都嫌烦？

我说这个结果一点不奇怪。因为你们买到的，本来就只有半个工具。

这是我在这几个月的课和讲座里反复讲的一个判断：AI 只能算半个工具。它有一半的能力是厂商给的，另一半，得靠你自己加上去。

工具的顶点，和 agent 的起点

我们这代人对工具的理解，是被旧工具塑造的。买一辆车、一台复印机、一套案例库，付款那一刻，它的能力就封顶了。所有人拿到的是同一个东西，差距顶多在熟练度上。

agent 把这个逻辑翻过来了。拿到的那天，它是起点，不是顶点。之后它长成什么样，取决于你喂了什么：你的执业习惯、你的判断框架、你踩过的坑、你希望它守住的底线。两个人用同一个模型、同一个产品，半年后的差距，可能大过两个人用不同的产品。

采购比价的思路在这里失效了。“用上就超越很多人”这句话，对复印机成立，对 agent 不成立。用上，只是拿到了那半个。

认知是乘数

这两年流行一种说法：AI 平权。意思是有了 AI，普通人也能干专家的活，差距被抹平了。

我对这个说法一直存疑。AI 更像一台智力放大器：你自己的认知是一，放大器乘的是倍数。认知很低的人，乘一个再大的倍数，加成也有限——他不知道该问什么，不知道答案哪里可疑，不知道怎么把一件复杂的事拆给机器。放大器放大的是你已有的东西，包括你判断力的上限，也包括它的边界。

还有一个更扎心的推论。工具越强，人和人的差距可能越大：强工具把高认知的人解放出来去做更难的事，而低认知的人，连第一个像样的问题都提不出来。工具平权了，结果反而更分化。这是我在自己团队和各次讲座里反复看到的现象，不是理论推演。

培养与管理

我这几个月真正体会到的一件事：更好用的那个 agent，是培养出来的。

它记得我的写作习惯，知道我写法律文书要演绎推理少用列表；它知道我做研究必须先查本地知识库再去商用数据库核验；它知道我每个工作区的边界在哪里。这些没有一条是厂商预设的，全是在一次次使用里“教”出来的。所以它需要培养，也需要被管理——像带一个实习生，教得好越用越顺手，放任不管，它永远停在第一天。

这个“教”的过程没有捷径。你把执业十几年攒下的默会知识一点点显性化、写进规则、存进记忆，它才有得可学。这个过程麻烦、琐碎、慢，但恰恰是它，构成了你和别人之间的差距。

有人说，这不就是“人不行怪人”吗

一种常见的反驳：厂商把产品做好不就行了，凭什么要用户自己“教”？

我承认厂商有责任，产品的下限确实由厂商决定。但 agent 这类产品的特殊之处在于，它的上限本来就有一部分设计在用户侧：喂给它的上下文是你的案卷，约束它的规则来自你的执业习惯，它记住的是你踩过的坑。这三样东西，任何厂商都给不了你。

所以这不是替厂商开脱。半个工具的意思是：一半在厂商手里，一半在你手里。前一半你控制不了，后一半全看你。

半年的窗口

还有个时间问题。我常跟学员讲：再过半年，可能你身边大家都在用。先行者的红利，不在抢先知道了什么功能——功能迟早人人会用。红利在于，你现在开始“教”、开始积累的那半个工具，别人到时候要从零开始。

下次比较 AI 工具的时候，别只问“它有多强”。先问问自己：另外那一半，你准备注入什么？
