厂商为什么拼命教你写 Skill？

本文目录 先回答标题的问题 先别急着警惕 但三个冷思考，供你上架前参考 资产表上的新科目

上个月我接到一个电话。对方在做某种 Skill 平台，问我：你 GitHub 上那两个开源的 Skill，可不可以放到他的平台上计价出售？

我说我都是开源的，还放什么放？

挂了电话我意识到一件事：一个市场正在形成，而且比我预想的快。

先回答标题的问题

如果你留意，会发现这两年的法律科技公司、甚至通用模型公司，都在极力推广 Skill 这个东西。办比赛、建市场、出教程，热情得很。

为什么？我在交流会上说过一句可能不太中听的大实话：很重要的是，他们需要你们的业务知识。

Skill 是一个极好的业务知识载体：自封装、可分享、热插拔，今天插在这个软件上能用，明天换一个也能用。你写了一个好 Skill，本质上是你把多年的业务经验整理成了一份可以直接执行的知识资产，放在了它的生态里。

厂商的收益至少有三重。第一重，你的知识充实它的平台内容。第二重，你的习惯长在它的平台上，迁移成本越来越高。第三重，未来的抽成市场——国外已经有收费 Skill 平台在运营，国内一定会出现，那通电话就是证据。

有一个反向佐证。你发现没有，厂商没什么兴趣推广工作区规则、记忆机制这些沉淀方法？原因很简单：那些东西沉淀完了就在你电脑里，出不来。Skill 不一样，打个包就能发给别人。

先别急着警惕

听到这里，你可能会觉得这是个“厂商收割律师”的故事。不是，至少不全是。

律师的经验从来不缺流通方式，缺的是可执行的流通方式。带徒弟，流通的是口耳相传的说法；写书，流通的是体系化的文字；讲课，流通的是一对多的演示。这三种我都干过，它们流通的都是“说法”——听懂了，回去还是你自己做。

Skill 是第四种形态，流通的是“做法”：别人装上你的 Skill，就等于把你处理这类事情的流程、标准和边界直接装进了他的工具里。

经验第一次可以脱离你本人，独立地在别人的电脑上干活。这是真实的机会，不该被警惕心盖过去。

但三个冷思考，供你上架前参考

冷思考一：定价的是经验，值钱的是更新。

法律是活的。司法解释一出，静态封装的 Skill 就开始过期。交流会上就有同行当场提出这个困惑：我今天封装好了，明天最高法新的解释出来了怎么办？所以真正值钱的不是那个文件包，是你持续维护它的能力。买家买的是一个切片，你手里的是生产线。想清楚这一点，定价心态会平和很多。

冷思考二：产品化不等于商业化。

温州有一位律师，做了破产债权计算的产品，基本上产品化成型了，后来又放弃了这条道路。我问过原因，主要是市场端困难。

这个对照组很重要。做出一个能用的东西，和让别人愿意为这个东西付钱，是两道完全不同的门槛。交流会上也有一位刚取得破产管理人资质的同行在开发同类工具，十几稿改下来，卡在了各地计算规则的差异上——深圳用 360 天，别的地方又不一样——最后开始自学编程。产品端已经这么难了，市场端只会更难。

冷思考三：想清楚什么上架，什么留作壁垒。

我上一篇文章里写过：能被蒸馏的是方法，蒸馏不出去的是壁垒。这句话放在这里的意思是，通用方法论可以上架，比如“怎么审一类合同”的框架；但你客户的习惯、你所在地域的裁判口径、你在具体交易里练出来的分寸感，这些要么没法封装，要么封装了也不该卖。

你的方法论一旦上架，对手也能买。这不是说不要卖，是说卖之前要知道自己在卖什么。

资产表上的新科目

律师的资产表上，过去主要是案源和声誉。现在多了一项：可执行的经验包。

我自己同时站在三个位置上：写过开源 Skill 的人、运营着聚合平台的人、参与律协采购讨论的人。从三个位置看同一件事，结论是一样的——这个市场会来，而且对认真沉淀的人是净好事。

只是接电话的时候，先想清楚上架什么、留下什么，再报价。
