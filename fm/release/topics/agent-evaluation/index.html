Training Data · Ronak Malde 11 月创刊号：如何留下能复用的判断

Harvey 的评估题从哪里来？先把专家判断做成能复跑的任务 ↗

Trajectory 联创 Ronak Malde 先说团队在 Windsurf 时，会从产品中的编辑、重试等实际行为寻找反馈。讲到 Harvey，他举了一个更具体的例子：Harvey 把法律专家积累的判断做成自己的法律 Agent 基准；按 Malde 的说法，一个开源模型在该基准上约从 4% 提升到 18%，他还称成本约为前沿模型的六分之一。随后他把过程拆开：先记下代理、子代理和反馈的任务轨迹，再把它恢复成可重跑的环境，最后才谈怎么训练。数字是供应商陈述，且只针对该基准；绝不表示整个法律工作流已经胜过前沿模型。
