换了更强的模型，旧 Skill 可能反而拖后腿 ↗

向阳乔木想重做录音设备的界面，先沿用一套在其他模型上表现不错的设计 Skill。换成 Fable 5.2 后，结果反而平常，他怀疑是旧指令收窄了新模型的发挥空间。歸藏补了反过来的观察：新模型写的 Skill 搬回其他模型，产出也可能变差。两人的讨论来自具体试用，没有做跨模型对照；它指出的是规则可能有适用范围，并没有证明 Skill 可以一概删掉。
