The Cognitive Revolution · Curt Tigges 11 月创刊号：如何留下能复用的判断

第二个 Agent 是在复核，还是在重复第一个？ ↗

Goodfire 的 Curt Tigges 讲他们研究模型为何产生某种行为时，会先让研究代理提出假说，做最小幅度的输入改动，再由相对独立的环节根据假说预测可测结果。预测错了，错误会回到研究流程继续迭代。这个方法的重点不在有两个模型，而在复核环节能否拿出不依赖原结论的检验；模型研究可观察的结果，也不能直接比作开放的法律判断。
