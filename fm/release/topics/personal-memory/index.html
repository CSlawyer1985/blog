AI 炼金术 11 月创刊号：如何留下能复用的判断

记忆放文本还是向量库，可能不是最难的决定 ↗

乔木备读记载，千问蒋冠军把问题放在记什么、记到什么粒度和多久还有效上。他举的例子里，用户说过某些事实，与系统据此做出的抽象判断不是一类东西；储存得太多会造成干扰，太少又无法理解用户。备读还提到他们用分层显示 Skill、降低重试等方式缩小上下文，效果为团队自述，并不是所有系统迁移后都能得到的数字。
