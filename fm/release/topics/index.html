GPU ↗

3 集 · 1 集核对官方文字稿 · 2 集附节目方提纲

从单卡规格看到实际算力交付：软件可否适配、集群和冷却怎样协调、实际任务成本落在哪些环节。供给或价格的讨论保留节目时间。

Personal Agent ↗

3 集 · 3 集附节目方提纲

把个人 Agent 当一类产品来读：用户要持续交给它什么任务、上下文怎样保留，外部服务能否把事项接完。单个产品的热度只反映其中一部分。

机制可解释性 ↗

3 集 · 3 集核对官方文字稿

把对内部信号的描述和干预结果放到一处看。模型激活出现规律、研究者能预测这类规律、干预后行为确实变化，是三种不同强度的证据。

持续学习 ↗

2 集 · 2 集核对官方文字稿

顺着任务记录、有效反馈和更新目标三步读。时效性强的事实与只属于单个用户的偏好，适合由外部状态提供；多次出现的共性失误才值得研究训练能否修正。

推理时扩展 ↗

2 集 · 2 集核对官方文字稿

用任务是否可验证、得分是否随额外推理预算变化这两条线理解推理扩展。现有材料收录实验者和算力供应商各自的说法。

CUDA ↗

1 集 · 1 集核对官方文字稿

目前的核心材料是黄仁勋回顾 CUDA 从消费端发行到建立开发者安装基础的过程。可从产品分发和技术兼容两条线理解，CUDA 与 GPU 是不同层次。

递归自我改进 ↗

1 集 · 1 集附节目方提纲

先区分有明确可测目标的局部反复优化，以及更强意义上的通用自我改进。现有节目提纲可以定位前一种实践，结论仍随实际任务及评估核验。

Agent 接力 ↗

5 条简报
