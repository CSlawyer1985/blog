多 Agent 各聊各的，哪些东西要存进共同的地方？

原段轻整理 · 非逐字引文

《词元之外》的讨论先区分随用随开的子任务与值得保留的长期会话，然后转向一个实践问题：如果今天用这个工具、明天换另一个，工作成果和过程到底去哪里。歸藏说，他会让不同 Agent 的产出回到同一个 GitHub 库；对谈里也举了用 Notion 的选择。讨论从会话保存推进到个人核心资料如何积累。它描述的是几个人各自的办法，不是让所有 Agent 共享全量资料的建议。

应用启示

给跨工具记忆做一个最小实验：只共享同一项目的任务编号、已验证决定、依据和最后进度。角色、账户授权和不该跨项目流动的资料保持分离，再测更换模型后能否接手。
