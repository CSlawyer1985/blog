21第 002 期行业故事11.09官方逐字稿锚定

链接一贴就被限流，他们改成只发 GitHub 仓库名

平台不让贴链接，他们把仓库名当成地址来用。

观点

歸藏的观察是：GitHub 仓库名是独一无二的，有了 AI 之后不必再贴链接，只要报出仓库名，对方就能找到对应仓库。

歸藏 · 26:09 · 发言人观察

「然后 AI 能力强了以后出现什么问题？我不贴链接。我贴个仓库名。你就用，你就跟他说我这个仓库名，他自然会基于这个仓库名去找 GitHub 对应的仓库。」

这是分发经验，不是对所有平台审核规则的保证。

故事

他回忆，Opus 刚火、很多人做网页的时候，最难的是怎么分发：抖音、小红书、Instagram、Facebook 都不让贴链接，一贴就限流，贴两次号可能没了。

歸藏 · 26:09 · 当事人回忆

「那个网页最难的是 Vibe Coding 怎么分发呢？所有的媒体，抖音、小红书、Meta 的那个 Instagram。Facebook 全部都不让你贴链接。……这些地方你一贴链接限流，一贴链接限流对吧？贴两回你号没了。」

对平台限流的口述，不是官方规则文本。

人物与产品

向阳乔木把它叫作小红书上的防封小技巧；橘子则说，这在某种意义上是社交媒体的 GEO，靠名字让人找得到。

向阳乔木、 橘子 · 27:10 · 发言人主张

「这就是防封小技巧，小红书上只提供仓库名可以吧。……对。这个就是，这个我觉得这个是某种意义上是叫社交媒体的 GEO。」

命名是现场概括。

应用启示

需要在限制外链的平台上分发仓库时，先试只提供可检索的唯一名称，并在自己的站点保留完整链接与说明。
