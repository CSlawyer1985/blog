手机接手一台一直在工作的 Mac，关键是能接住会话

原段轻整理 · 非逐字引文

乔木备读记录了鸭哥的这一套用法：Mac 上的任务可以一直跑，手机上他需要的是看清现有会话、对话与语音入口；机器部署和人最后的验收，不在同一层。开发者自己的公开项目可核对其中一部分：这是一个连接 OpenCode Server 的 iOS 客户端，可看会话、文件差异和工具调用。访谈所述的完整协同和验收流程则是他的个案体验，这些能力不能全部归到该客户端。

应用启示

可以当作手机控制 Agent 的竞品问题：用户真正想接手时，需要的是看到正在做什么、能给下一条指令、知道哪一步等人确认；远程触控板解决的是另一个问题。
