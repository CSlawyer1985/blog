15第 002 期讲课素材11.11官方逐字稿锚定

两个 Agent 都说「核心争点」，讲的是不是同一个？

两个 Agent 都说在朝一个目标走，并不等于他们说的是同一件事。

观点

Vijoy Pandey 说，他们观察过多 Agent 系统后发现：表面上已经连上、也像在朝一个目标工作，但语义上并未对齐，各自停在局部最优；系统里已有的评估也多是在测单个 Agent，而不是多 Agent。

Vijoy Pandey · 33:12 · 发言人主张

“what we realized when we started looking at these multi agent systems is that they might appear connected and they might be working towards a goal, but semantically, they were not aligned at all. … So all of the evals that existed in the system were measuring these agents in an in an individual manner, not in a multi agent manner.”

Cisco / Outshift 一侧的观察总结，不是对某公开基准的复现结果。

人物与产品

Vijoy Pandey 来自 Cisco Outshift，把多 Agent 的问题说成语义对齐，而不是只把节点连上。具体产品名与协议能力以原访谈和项目文档为准。

Vijoy Pandey · 33:12 · 发言人主张

“they might appear connected and they might be working towards a goal, but semantically, they were not aligned at all.”

厂商一侧的观察，不是独立评测。

应用启示

可以做一张课上对照卡：同一份诉讼材料，让一个 Agent 按金额排序，另一个按法官追问排序。两者都叫它「核心争点」时，不直接裁决谁错，而是先把排序标准和应由谁拍板写进交接。
