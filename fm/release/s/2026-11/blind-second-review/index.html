16第 002 期法律 AI 实务11.11官方逐字稿锚定

第二个 Agent 是在复核，还是在重复第一个？

复核有没有用，要看它能不能在假说失败时把错误送回去，而不是再附和第一遍。

观点

Curt Tigges 描述他们的工作流：让代理根据假说，去预测一段文本里某个神经元会在何处、以多强的程度兴奋；如果描述不好、预测失败，错误会回到研究者一侧，再调整假说。

Curt Tigges · 44:01 · 发言人观察

“And this will happen for, like, a few texts. And then if it fails, if the description just isn't good, then it'll come back to the neuroscientist with feedback. It will see how it needs to adjust its hypothesis, improve it a little bit, send it back, and so forth.”

这是 Goodfire 研究流程的当事人描述，不能直接比作开放的法律判断。

人物与产品

对话围绕 Goodfire 对神经元可解释性的研究，以及用代理去检验假说、再把结果整理成页面的做法。

Curt Tigges · 44:02 · 发言人观察

“And then at the end, a helper agent will create a page that basically shows us the results of what the hypothesis is.”

研究工具链描述，不是产品发布说明。

应用启示

法律稿复核可以不先给第二个 Agent 看第一稿意见，只交给它争点、证据原文及适用日期，要求独立做一条反例检索。再比较两者证据链，而不是问第二个模型同意不同意。

The Cognitive Revolution · Curt Tigges
